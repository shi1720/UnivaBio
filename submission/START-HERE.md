# Looplight — Shivam's hackathon kit

**The idea:** a pending result should not disappear when someone leaves hospital. Looplight connects unfinished follow-ups to their original instructions, a tracking person, and a user-reported ending.

- **App:** https://looplight-shivam.sg127977958.chatgpt.site
- **Code:** https://github.com/shi1720/UnivaBio
- **Scope:** working research MVP; fictional or de-identified notes only. No paid model API is required.
